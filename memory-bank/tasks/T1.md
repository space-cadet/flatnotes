## Description
Add support for public/private visibility on individual notes in flatnotes. Currently, flatnotes auth is global (all-or-nothing). This feature allows some notes to be publicly readable while others require authentication.

## Completion Criteria
- [x] Parse YAML frontmatter from note files
- [x] Write visibility metadata on save
- [x] Conditional auth: public notes readable without auth
- [x] Search filters results by auth status
- [x] Visibility toggle in note editor UI
- [x] Public-first homepage (no forced login)
- [ ] Frontend bundle rebuild and retest after NavBar/router changes
- [ ] UI polish: visibility toggle styling, login-required messages
