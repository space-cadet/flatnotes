# T2: Add LaTeX Math Support

## Description
Add KaTeX-based LaTeX math rendering to flatnotes. Support inline math ($...$) and block math ($$...$$) delimiters.

## Implementation Summary
- Added `katex` v0.16.23 to `package.json` dependencies
- **Approach v1**: Used KaTeX auto-render on rendered HTML — failed because Toast UI's markdown parser mangles backslashes inside `$$...$$` blocks (`\alpha` → `\ alpha`)
- **Approach v2 (final)**: Extract math blocks BEFORE Toast UI sees them, replace with HTML `<span>` placeholders that Toast UI passes through unchanged, then render with KaTeX after Toast UI finishes
  - `preprocessMath()` extracts `$...$` and `$$...$$` blocks, base64-encodes the LaTeX, injects `<span class="math-placeholder" data-display="inline|block" data-math="...">`
  - `renderMath()` finds placeholders after Toast UI renders and replaces with `katex.renderToString()` output
- Modified `ToastEditor.vue` to import KaTeX CSS (styles available for preview)
- Uses standard `$...$` inline and `$$...$$` block delimiters
- `throwOnError: false` prevents rendering failures from breaking the page
