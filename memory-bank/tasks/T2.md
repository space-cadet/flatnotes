# T2: Add LaTeX Math Support

## Description
Add KaTeX-based LaTeX math rendering to flatnotes. Support inline math ($...$) and block math ($$...$$) delimiters.

## Status
**Completed & Deployed** ✅

## Verification

- Auto-render code confirmed in built `Note-*.js` bundle

- Test note `latex-test.md` created with sample LaTeX content

## Implementation Summary
- Added `katex` v0.16.23 to `package.json` dependencies
- Modified `ToastViewer.vue` to import KaTeX CSS and auto-render math after mounting
- **Fixed backslash escaping**: Added `preprocessMath()` helper that double-escapes backslashes inside `$...$` and `$$...$$` blocks before passing to Toast UI Viewer — Toast UI's markdown parser (`to-mark`) strips backslashes from unknown escapes, breaking LaTeX commands like `\int`, `\sum`, etc.
- Recreate viewer on content changes (needed for proper re-render with pre-processed math)
- Modified `ToastEditor.vue` to import KaTeX CSS (styles available for preview)
- Uses standard `$...$` inline and `$$...$$` block delimiters
- `throwOnError: false` prevents rendering failures from breaking the page
